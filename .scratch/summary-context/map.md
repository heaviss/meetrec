# Контекст и стоимость summary

## Destination

В `SPEC.md` описано, откуда summarizer берёт контекст прошлых встреч и сессий Claude Code и какой у `summary_command` дефолт (модель, effort) по замерам токенов и качества. Код пишется отдельно, после карты.

## Notes

- Тикеты-решения, не код. Читать перед работой: `SPEC.md` (раздел summary, → 07), `wayfinder/07-summary.md`, `meetrec/prompt.md`.
- Транскрипт — чужая речь, недоверенный вход: summarizer не получает инструментов на запись, на сеть и Bash.
- Реальные встречи и сессии Claude Code остаются вне репо; в репо попадают только агрегаты: токены, $, оценки.
- Для grilling-тикетов вызывать skills `grilling` и `domain-modeling`.

## Decisions so far

- [Как устроены сессии Claude Code на диске](01-claude-code-sessions.md): JSONL в `~/.claude/projects`, 3,2 ГБ, полно секретов в выводе инструментов; summarizer видит только выжимку meetrec (промпты, ответы, `cwd`, даты) через фильтр секретов, без `Read` по сырым файлам.
- [Что `claude -p` позволяет ограничить и замерить](02-claude-p-flags.md): только чтение — `--tools Read,Grep,Glob` + `--strict-mcp-config`, пути — `--add-dir=`; `--model`/`--effort`; `--output-format json` даёт `total_cost_usd`; Haiku в ~20–40 раз дешевле Opus.
- [Кто подбирает контекст: агент или meetrec](03-context-source.md): агент — `Read,Grep,Glob` с cwd в папке, которую собирает meetrec (прошлые встречи и выжимки сессий за 14 дней); +$0,2 и до 25 с на встречу, находит связи с тикетами, которые пропускает отбор по словам.

## Not yet specified

- Как оценивать качество summary при сравнении моделей: рубрика, кто ставит оценки (человек, LLM-судья).
- Термины для «контекста из прошлого» и «списка людей» в `GLOSSARY.md`, когда устоится.

## Out of scope

- Поиск тикетов и страниц документации через MCP: транскрипт — недоверенный вход, а инструменты MCP дают prompt injection доступ к внешним системам. Отменено при постановке карты.
- Автоудаление аудио старше N дней (`audio_retention_days`): решено при постановке (удаляем только `*.wav` у расшифрованных встреч, возраст от старта, проверка при старте демона и после обработки, `0` = выкл), сделано отдельно, без карты.
