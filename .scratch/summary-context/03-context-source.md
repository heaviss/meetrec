# Кто подбирает контекст: агент или meetrec

## Question

Откуда summarizer берёт контекст прошлых встреч (`summary.md`, `transcript.md` в `recordings_dir`) и сессий Claude Code?

- (a) Агент с инструментами только для чтения, ограниченными этими папками, сам ищет релевантное.
- (b) meetrec детерминированно отбирает контекст (общие номера тикетов, термины) и кладёт в stdin; инструменты выключены.

Для сессий Claude Code вариант (a) ограничен решением [Как устроены сессии Claude Code на диске](01-claude-code-sessions.md): агент читает только выжимку, которую готовит meetrec, не сырой JSONL.

Сравнить на 2–3 своих встречах: полезнее ли summary, сколько токенов, сколько времени.
