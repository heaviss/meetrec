# Как meetrec выбирает язык встречи

## Question

Как выбирается язык: настройка `language` в конфиге, автоопределение по записи или выбор на каждую встречу. Что делать со встречей, где говорят на двух языках. Какие модели качает `meetrec setup`: только для выбранного языка или все. На каком языке пишется `summary.md` и как меняется `prompt.md`.

## Resolution

- Язык задаёт `language = "ru" | "en"` в конфиге, по умолчанию `ru`. Одну встречу можно пересчитать на другом языке: `meetrec redo --language en <встреча>`. Автоопределения нет.
- Встреча с двумя языками не поддерживается: её расшифровывает модель языка из конфига; README это называет.
- `meetrec setup` качает только модель языка из конфига; сменил язык — запусти `setup` ещё раз.
- `summary.md` пишется на языке встречи: `prompt.md` по-английски, со строкой «write the summary in {language}»; заголовки разделов модель пишет на том же языке.
