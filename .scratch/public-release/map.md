# Открыть репозиторий meetrec

## Destination

План публикации `plan.md` в этой папке, который выполняется за одну сессию. Он перечисляет правки в рабочем дереве, файл замен для `git filter-repo --replace-text` и смены почты, а также порядок шагов: переписать историю, сделать force-push, открыть репозиторий на GitHub. Все решения приняты, осталось выполнить.

## Notes

- Читатель — посторонний пользователь Linux с PipeWire и `systemd --user`. Другие ОС и дистрибутивы не поддерживаем; для macOS и Windows README ссылается на [amanu](https://github.com/gsamat/amanu).
- Принятые решения:
  - историю сохраняем и переписываем через `git filter-repo`; force-push только после явного «да» пользователя;
  - `wayfinder/` остаётся как история проектирования, из неё вычищаются цитаты настоящей встречи и ссылки на work-repo;
  - почта коммитов — GitHub noreply `<id>+heaviss@users.noreply.github.com`;
  - лицензия MIT, если её допускают зависимости;
  - README по-русски, наверху абзац по-английски: что это и что поддерживается только русская речь; SPEC и wayfinder остаются по-русски;
  - `user_name` по умолчанию берётся из GECOS (`getent passwd`), если его нет — из логина; у `glossary_repo` умолчания нет, без него саммари пишется без словаря;
  - CLAUDE.md остаётся инструкцией для агентов любого контрибьютора, без почты и личных правил пуша;
  - ветки `prototype/*` остаются локальными и никогда не пушатся.
- Для grilling-тикетов: навыки `grilling` и `domain-modeling`.
