# Что README говорит постороннему

## Question

Как устроен README для человека, который видит проект впервые, и как его перевести: английский README главный, а русский — отдельным файлом или не нужен. Состав: языки речи, требования (Linux, PipeWire, `systemd --user`, `uv`, CLI `claude`, по желанию Vulkan и LocalVQE), установка, пример конфига с общими значениями, где лежат встречи, ссылка на amanu для macOS и Windows, лицензия и атрибуция зависимостей. Что из нынешнего README относится только к машине автора и уходит.

## Resolution

- Только английский `README.md`, русской версии нет.
- Установка: `uv tool install git+https://github.com/heaviss/meetrec --python 3.14`, `meetrec setup`; обновление `uv tool upgrade meetrec`. `--editable` из клона — в CLAUDE.md для тех, кто правит код. PyPI — не в этом плане.
- Разделы: что делает; приватность (звук на машине, текст транскрипта уходит в Anthropic через ваш `claude`); языки (`ru` — GigaAM, `en` — Parakeet, смешанные не поддерживаются); требования (обязательные и для подавления эха); установка и обновление; использование; настройка с общим примером; чистка записей; ограничения (браузеры держат микрофон при выключенном звуке → пауза 30 с; приложение Zoom не проверено; датчик гнезда наушников бывает сломан); альтернатива для macOS и Windows — [amanu](https://github.com/gsamat/amanu); сторонние компоненты и лицензия MIT.
- `claude` необязателен: если его нет в `PATH`, демон пропускает саммари и отмечает это в `meta.json`, транскрипт пишется как обычно.
- `glossary_repo` остаётся как есть; README объясняет, что демон берёт все `GLOSSARY*.md` из этого git-репозитория.
