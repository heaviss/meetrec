# Как ставить LocalVQE по желанию

## Question

`echo_cancel` по умолчанию выключен, а `meetrec setup` всё равно клонирует и собирает LocalVQE: для этого нужны `git`, `g++` и `cmake`. Как сделать установку по желанию: собирать только при `echo_cancel = true`, отдельная команда или флаг `setup`? Что делает демон, если `echo_cancel = true`, а библиотеки нет? Попутно убрать то, что годится только для этой машины: `-j6` в `install.py` и перенос из старого `~/.cache/meetrec`.

## Resolution

- Установку включает `echo_cancel = true` в конфиге: `meetrec setup` качает модель LocalVQE, клонирует и собирает библиотеку только при ней. Включил настройку позже — запустить `setup` ещё раз.
- `echo_cancel = true`, а библиотеки или модели нет: демон при старте один раз шлёт уведомление «эхо не подавляется: запустите `meetrec setup`». Встречи идут с сырым `me.wav`, как сейчас при сбое подавления.
- Сборка: `uvx cmake --build ... --parallel` без числа вместо `-j6`.
- `OLD_CACHE` и перенос из `~/.cache/meetrec` удалить.
- Сборка остаётся через `uvx cmake`; `git` и `g++` нужны только для подавления эха, так и написать в README.
